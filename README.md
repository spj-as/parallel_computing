# Stanford CS149 - Parallel Computing

Coursework and programming assignments for Stanford CS149: Parallel Computing (Fall 2023).

## Topics Covered

- Multicore CPU architecture
- SIMD and ISPC
- GPU programming with CUDA
- Spark and distributed computing
- Cache coherence and memory consistency
- Parallel performance optimization
- Task scheduling and synchronization
- Hardware specialization and FPGA concepts

## Programming Assignments

### Assignment 1
Analyzing parallel program performance on a quad-core CPU.

### Assignment 2
Scheduling task graphs on a multi-core CPU.

### Assignment 3
Building a simple renderer in CUDA.

### Assignment 4
Implementing a Flash Attention Transformer model.

### Optional Assignment 5
Big graph processing.
